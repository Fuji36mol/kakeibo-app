# kakeibo-app
# 家計簿アプリ

収入・支出を記録し、集計やグラフで確認できるコマンドラインツールです。
何にいくら使ったかを手軽に把握し、予算を超えそうなときに気づけることを目的にしています。

## できること

| 番号 | 機能 | 内容 |
|---|---|---|
| 1 | 記録を入力 | 日付・収入/支出・カテゴリ・金額・メモを入力して保存（日付は空欄で今日） |
| 2 | 一覧を表示 | すべての記録を番号付きで表示 |
| 3 | 記録を削除 | 一覧から番号を選んで1件削除 |
| 4 | 集計を表示 | 合計・残高、カテゴリ別の集計 |
| 5 | グラフを表示 | カテゴリ別の支出を棒グラフで表示し、今月の予算と比べて警告 |
| 0 | 終了 | |

## 使い方

```
pip install -r requirements.txt
python main.py
```


## 使用したOSS

- **rich**：ターミナルの文字に色を付けたり、表を整えたりできるライブラリです。
  コマンドプロンプトで動くアプリなので、画面の中で見やすく表示できる rich を選びました。

## データの形

記録は `data.json` に保存されます（`.gitignore` で除外しているため、GitHubには上がりません）。
1件の記録は次の項目を持つ辞書です。

- date：日付（文字列、例："2026-10-13"）
- type：収入 または 支出
- amount：金額（正の整数）
- category：カテゴリ（文字列、例："食費"）
- memo：メモ（文字列、空でもよい）

例：

```json
{"date": "2026-10-13", "type": "支出", "amount": 850, "category": "食費", "memo": "昼ごはん"}
```

## storage.py の関数

- load_records(path="data.json") → 記録のリストを返す。ファイルがなければ空のリスト
- save_records(records, path="data.json") → 記録のリストを保存する

## 開発の進め方

開発を4つのフェーズに分け、フェーズごとに「作る人」と「レビューする人」を交代しました。

| フェーズ | 内容 | ブランチ | 作る人 | レビュー |
|---|---|---|---|---|
| 1 | データの読み書き、メニューの骨組み | feature-storage | 小渕 | 岩月 |
| 2 | 入力・一覧表示・削除 | feature-phase2-records | 岩月 | 小渕 |
| 3 | 合計・残高、カテゴリ別集計 | feature-summary | 小渕 | 岩月 |
| 4 | グラフ表示、予算の警告 | feature-phase4-report | 岩月 | 小渕 |

ルール：

- 作業は必ず機能ごとのブランチで行い、main には直接コミットしない
- main への取り込みは、プルリクエストを作成し、相手のレビュー（Approve）を受けてからマージする
- 作業を始める前に `git pull origin main` で最新の状態にする
